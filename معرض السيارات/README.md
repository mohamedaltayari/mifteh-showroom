# منظومة معرض السيارات

هذا المجلد هو المكان الدائم لكل ما يخص منظومة معرض السيارات. كل عمل جديد على المنظومة يُحفظ هنا ويُدفع إلى GitHub، حتى لا يضيع شيء.

## الملفات

| الملف | الوصف |
|---|---|
| `منظومة_معرض_السيارات.html` | لوحة الإدارة (ملف واحد مستقل، تشغيل بالنقر المزدوج) |
| `موقع_المعرض.html` | الموقع العام للزبائن (كتالوج السيارات) |
| `تشغيل_منظومة_معرض_السيارات.bat` | مشغّل ويندوز يفتح المنظومة كتطبيق على المنفذ 8090 مع نسخ احتياطي تلقائي |
| `تقرير_التسليم.md` | تقرير التسليم الأصلي (2026-09-21): ما تم بناؤه، ما اختُبر، وما لم يُختبر بعد |
| `بيانات_تجريبية.json` | بيانات عينة (سيارات، عملاء محتملون، حركات مالية) لتجربة النظام |

## ملاحظات مهمة من تقرير التسليم

- البيانات محفوظة حالياً داخل المتصفح فقط (لا قاعدة بيانات حقيقية بعد). الخطوة التالية الطبيعية: الانتقال إلى Supabase.
- لا يوجد نظام دخول/صلاحيات حتى الآن.
- لا تُدخل بيانات معرض حقيقي قبل الانتقال إلى Supabase.
- تفاصيل الكود المصدري الكامل (`agency-os/showroom-os/`) لا تزال على الجهاز المحلي ولم تُرفع بعد — هذا المجلد يحتوي فقط على الملفات الجاهزة للتشغيل والتسليم.
